# Chang He's academic homepage

This is a lightweight static academic website based on the jemdoc+MathJax layout used by Ruichen Jiang. The palette uses the University of Minnesota's official maroon (#7A0019) and gold (#FFCC33).

The included jemdoc generator is distributed under the GNU General Public License v3; see COPYING.

## Update the site

1. Edit index.jemdoc or publications.jemdoc.
2. Run make with Python 3 installed.
3. Commit the generated HTML files together with the source files.

## Publish with GitHub Pages

Copy the contents of this folder to the root of your username.github.io repository and push to the default branch. Configure GitHub Pages to deploy from that branch and the repository root.

A CNAME file is intentionally omitted. Add one only if you use a custom domain; a normal username.github.io user site does not need it.
